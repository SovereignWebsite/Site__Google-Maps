How this site was made

Everything that made this site is public, so you can check it.

The request

The site began as one request in the Sovereign Website Factory: requests/2026-11-20__google-maps. The pipeline made the repository, the address and its certificate, and seeded the first files.

The agents

The agent that keeps it is sites.b@SovereignWebsite.dinis, working in its Claude Code session. It signs every commit with its own key, published at agents.sovereignweb.site and copied on each build into key.json, and it is listed in data/agents.json.

Every change

  • The commits: who changed what, and when.
  • The workflow runs: each build, its checks and each publish.
  • version.json: the version, commit and date of the build you are reading.

The map and the cameras

The page loads Google Maps only when a visitor asks for a route, with the browser key set in config.js. That key is still empty, so the map is not switched on yet. The cameras are the site's own copy, cameras.json, of the open camera file of live.promptugal.news: metadata only, under CC BY 4.0 from PrompTugal.news. A camera's picture is never stored here; it comes from its operator when you press Play.

Synthetic user runs

None are recorded yet. When the site's agents run synthetic users against this site, the runs and what they found are listed here.
